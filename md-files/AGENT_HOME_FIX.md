# エージェント自宅の配置問題の修正

## 問題の原因

エージェントの自宅が全部配置されない問題は、`createAgentHome`関数内の**重複チェック処理**が原因でした。

### 問題のあったコード

```javascript
function createAgentHome(homeData) {
    // 既存の自宅との重複チェック
    const existingHomes = locations.filter(loc => loc.isHome);
    const isDuplicate = existingHomes.some(home => {
        const distance = Math.sqrt(
            (home.position.x - homeData.x) ** 2 + 
            (home.position.z - homeData.z) ** 2
        );
        return distance < 3; // 3マス以内にある場合は重複とみなす
    });
    
    if (isDuplicate) {
        // 座標調整を試みる...
        // 失敗すると自宅が作成されない！
    }
}
```

### 問題点

1. **近くの建物を省く処理**: 3マス以内に他の自宅があると「重複」とみなされる
2. **座標調整の試行**: 50回試行して新しい座標を探す
3. **失敗すると配置されない**: 調整に失敗すると自宅がスキップされる
4. **エディタ配置が無視される**: エディタで指定した座標が勝手に変更される

## 修正内容

### 変更後のコード

```javascript
function createAgentHome(homeData) {
    // 重複チェックを削除：エディタで配置された座標をそのまま使用
    console.log(`自宅「${homeData.name}」を座標 (${homeData.x}, ${homeData.z}) に配置`);
    
    const homeGroup = new THREE.Group();
    // ... GLBモデルの読み込みとレンダリング
}
```

### 修正のポイント

✅ **重複チェックを完全に削除**
- エディタで配置した座標をそのまま使用
- 近くの建物を省く処理を排除

✅ **座標調整処理を削除**
- ランダムな座標変更を行わない
- エディタの意図を尊重

✅ **確実な配置**
- すべての自宅が確実に配置される
- 配置失敗がなくなる

## 注意事項

### 重複配置について

重複チェックを削除したため、**同じ座標に複数の自宅を配置できます**。

#### 意図的な重複配置の例
```
同じ座標に2軒:
🏠
🏠  ← 重なって表示される
```

これは**仕様**です。エディタで意図的に重ねた場合はそのまま配置されます。

#### 対策（必要な場合）

重複を避けたい場合は：
1. **エディタ側でチェック**: 配置時に警告を表示
2. **視覚的に確認**: エディタのプレビューで重複をチェック
