# GLBモデルキャッシュシステム

## 概要

GLBモデルのキャッシュシステムを実装しました。これにより、同じGLBファイルを使用する複数の建物がある場合、ファイルを一度だけ読み込み、その後はキャッシュから再利用します。

## 主な機能

### 1. GLBモデルキャッシュ (`glbModelCache`)
- 一度読み込んだGLBモデルをメモリに保存
- 同じファイルへの再アクセス時は、キャッシュからクローンを作成して返す
- ファイルI/Oを削減し、読み込み速度を大幅に向上

### 2. 読み込み中の管理 (`glbLoadingPromises`)
- 同じファイルを複数の建物が同時に要求した場合の処理
- 最初のリクエストのみが実際にファイルを読み込む
- 後続のリクエストは最初のPromiseを待機し、完了後にクローンを取得

### 3. 汎用ヘルパー関数 (`createBuildingFromGLB`)
- 建物作成コードを共通化
- パラメータで色、位置、スケールなどを指定
- フォールバック機能も統合

## 使用方法

### 新しい方法（推奨）

```javascript
function createLibraryBuilding(locationGroup, facilitySize, facilityHeight, color, scale) {
    createBuildingFromGLB(
        'src/glb/ComfyUI_00005_library.glb',  // GLBファイルパス
        locationGroup,                          // 配置先グループ
        facilitySize,                           // サイズ
        facilityHeight,                         // 高さ
        0x87CEEB,                               // 色（SkyBlue）
        scale,                                  // スケール
        '図書館',                                // 建物名（ログ用）
        createFallbackLibrary,                  // フォールバック関数
        2.5                                     // Y位置（オプション、デフォルト: 0.5）
    );
}
```

### 古い方法（非推奨）

```javascript
function createLibraryBuilding(locationGroup, facilitySize, facilityHeight, color, scale) {
```

## メリット

1. **読み込み速度の向上**: 同じファイルを何度も読み込まない
2. **メモリ効率**: 元のモデルを1つだけ保持し、必要に応じてクローン作成
3. **コードの簡潔化**: 冗長なコードが大幅に削減
4. **メンテナンス性**: 共通ロジックの変更が容易

## 注意事項

- キャッシュはページリロードまで保持されます
- 大量の異なるGLBファイルを使用する場合、メモリ使用量に注意
- `.clone()`を使用しているため、各建物は独立したインスタンス
